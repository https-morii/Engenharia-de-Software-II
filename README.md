# Site de Receitas

No nosso site de receitas os usuários podem se cadastrar, fazer login, explorar diversas receitas culinárias e conhecer mais sobre o site.

---

## Sobre o Projeto

Este projeto consiste em uma aplicação web desenvolvida para facilitar o acesso e a descoberta de novas receitas. O sistema conta com controle de acesso para usuários e navegação por conteúdos institucionais e culinários.

### Fluxo do Processo (BPMN)

1. **Acesso:** O usuário entra na tela inicial.
2. **Autenticação:** O sistema verifica se o usuário possui cadastro:
   - **Sim:** Redireciona para o **Login**.
   - **Não:** Redireciona para o **Cadastro** e, em seguida, para o **Login**.
3. **Navegação:** Após o login, o usuário pode explorar simultaneamente:
   - **Explorar Receitas**
   - **Ver sobre o site**

---

## Tecnologias Utilizadas

- **Frontend:** React + TypeScript + Vite + HTML + CSS+ JavaScript
- **Modelagem de Processos:** BPMN 2.0 (bpmn.io / Bizagi)
- **Controle de Versão:** Git & GitHub
